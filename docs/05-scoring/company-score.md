# 公司研究与评分（v1.4）

当前实现为粗筛分数，不能解释成内在价值或成功概率。完整决策契约见 [AI 投资修订](../11-ai-investment-revision.md)。

- 成长 40%：营收同比；估值 15%：PE/营收增速的粗筛参考；质量 30%；技术面 15%。暂保留原权重以隔离修复影响，未经样本外评估不宣称最优。
- 质量内部：毛利率 50%、现金流正负 30%、ROE 20%，仅对已知项归一化；FCF 未知不作负值，ROE=0 不作缺失。
- `data_coverage` 报告五项财务输入覆盖率；`fundamentals_ready` 要求营收、毛利率、FCF 齐备。分数可展示，但不齐备时最终信号不得高于 watch，计划新增仓位系数为 0。
- 采集年度经营现金流、资本开支、FCF、净债务、股数、来源及时间。它们不是多年历史财报库；PE 和成长也不是同一财务期间的完整估值模型。
- optical/custom_interconnect/turnaround/energy_infra 支持显式分类。各类经营证据和情景估值框架见修订方案，尚未自动生成估值区间。
