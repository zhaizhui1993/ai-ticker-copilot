# 汇总与决策约束（v1.4）

四维仍默认等权，分档 ≥70 积极 / ≥50 中性偏多 / ≥30 中性偏空 / <30 防御。分数仅排序，未经过胜率校准。

Engine 处理已知体制破位和公司低分；pipeline 附加数据与日历约束；analyzer/constraints.py 对真实 LLM 与规则降级结果执行同一最终校验：

| 条件 | 动作上限 | position_cap |
|---|---|---|
| 数据齐备、无额外约束 | accumulate | 1 |
| 体制破位 | watch_add | 0.3 |
| 公司分<35 | watch_add | 1（若同时破位为0.3） |
| 体制未知、关键财务/行情不足、日历未知 | watch | 0 |
| 财报/FOMC 在未来3个自然日内（含当天） | watch | 0 |

position_cap 是计划新增仓位的比例上限，不是总资产百分比。多重条件取严格者；减仓信号不被改为加仓。被代码降低动作时置信度最高0.5并附原因。
最终股票集合必须与输入一致；缺失或重复股票使用规则结果，池外股票移除。未知数据与风险约束不能靠提示词执行。
