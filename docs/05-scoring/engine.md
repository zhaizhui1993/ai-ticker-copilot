# 05-评分 ｜ 汇总与分档（engine.py）

> 模块：05 评分引擎 ｜ 成分：加权汇总 + 信号分档 + 体制层硬约束 ｜ 实施阶段：P5
> 来源：原方案 §6.1（汇总与分档）+ v1.1 硬约束

## 加权汇总

默认权重 0.25×4（`scoring_weights.yaml` 可调，校验合计=1.0）；总分 = Σ wᵢ·sᵢ。

## 信号分档

| 总分 | 含义 | 信号倾向 |
|---|---|---|
| ≥70 | 积极 | 建仓/加仓 |
| 50~70 | 中性偏多 | 观望偏加仓 |
| 30~50 | 中性偏空 | 观望 |
| <30 | 防御 | 减仓/回避 |

**分数是锚点不是结论**：LLM 可偏离分档输出信号，但 prompt 强制要求偏离时在理由中说明（"尽管总分中性，但考虑到 X 因素……"），保证分数与结论互相印证。

## 体制层硬约束（v1.1 新增）

当 [layered-technicals.md](layered-technicals.md) 体制层判定破位（两个及以上指数收盘 < MA200，或任一指数 < MA200 且 VIX>25）时，所有个股信号档位上限压至"观望"；LLM 如需上偏必须额外援引事件类比依据。该约束保证"环境关门时不看多任何个股"，宏观/事件环境不进入加权求和、只做门槛。
