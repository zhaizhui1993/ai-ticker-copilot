# 08-Web ｜ 前端页面（五个页签）

> 模块：08 Web 面板 ｜ 成分：页面定义 ｜ 对应代码：web/static/ ｜ 实施阶段：P8
> 来源：原方案 §8.2

| 页签 | 内容 |
|---|---|
| **总览** | 股票卡片（现价/当日涨跌/信号徽章颜色/总分）；近 30 日信号折线（ECharts line）；四维雷达图（radar）；宏观仪表条（联邦利率/CPI/VIX 数值+方向箭头）；数据源状态（各源最近抓取时间） |
| **个股详情** | K 线（candlestick + MA20/MA50，3M/6M/1Y 缩放）；四维分条形图；基本面指标表（增速/PE 分位/毛利/RSI）；该股相关当前事件与历史类比卡 |
| **事件中心** | 四类事件流（宏观政策/国际热点/行业/企业，Tab 切换）；**新事件 30s 自动刷新 + 未读徽章**；经济日历未来 7 天预告条；每条事件展开历史类比（相似度、类比事件名、历史同类事件对池内标的的平均影响与恢复时间）；历史事件库浏览/新增表单 |
| **X 观点** | 博主列表、帖子流（按博主/股票筛选）、情绪分布饼图；cookie 状态提示（失效时一键引导运行导出脚本） |
| **分析页** | 两个按钮："用现有数据立即分析" / "刷新数据并分析"；结果卡片（信号/置信度/理由/风险/免责声明）；历史分析列表 |
