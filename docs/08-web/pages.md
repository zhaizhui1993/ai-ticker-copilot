# 08-Web ｜ 前端页面（六个页签）

> 来源：原方案 §8.2

| 页签 | 当前实现 | 规划增强 |
|---|---|---|
| **总览** | 股票卡片（现价/当日涨跌/信号徽章）；指数体制层条（^GSPC/^NDX/^SOX vs MA200、VIX、费半 ATR14）；数据源状态 | 近 30 日信号折线、四维雷达图、宏观仪表条（利率/CPI） |
| **个股详情** | K 线 + MA20/MA50（3M/6M/1Y 窗口切换）；技术指标表（RSI14/ATR14/量比/回撤/乖离） | 四维分条形图、基本面指标表、相关事件与类比卡 |
| **事件中心** | 当前事件流（标题/摘要/涉及标的 + **价格反应徽章**：事件日涨跌/前 5 日/距 52 周高，红绿着色）；新事件自动刷新 + 未读徽章；经济日历未来 7 天预告；历史事件库浏览表格（DB 不可用降级展示种子文件） | 每条事件展开历史类比、历史库新增表单（API 已有 PUT） |
| **X 观点** | 博主列表表格；登录态提示（crawl 模式 cookie 未就绪时引导运行导出脚本或切 X_MODE=api） | 帖子流（按博主/股票筛选）、情绪分布饼图（待打标管线） |
| **分析页** | 两个按钮："用现有数据立即分析" / "刷新数据并分析"；结果卡片（信号/置信度/理由/风险/免责声明）；历史分析列表 | — |
| **对话**（增补） | 研究助理多轮问答（POST /api/chat，Enter 发送、示例提问）；固定免责声明；LLM 未配置时提示"对话是唯一强依赖 LLM 的功能" | 服务端会话记忆（当前会话历史由浏览器持有） |
