## 1.1 背景与目标

个人使用的分析辅助系统：基于**宏观经济政策、国际热点事件、X 财经博主发言、企业/产业基本面**四个维度，辅助判断 AI 产业链美股"**建仓还是加仓**"。

核心特色是**历史事件类比**：当前发生的宏观政策、国际事件、贸易摩擦，与历史事件库（2018 贸易摩擦、2022 激进加息、历轮对华芯片出口管制、DeepSeek 冲击等）做相似度匹配，用历史事件的实际市场反应（最大回撤、达底天数、恢复天数）辅助研判当前影响。

另一核心能力是**准实时事件跟进**：以默认 20 分钟（可配）为周期轮询多类信息源，增量采集**宏观经济政策、国际热点、行业（AI 产业链）、企业（股票池公司）**四类当日事件，新事件到达即去重、结构化、富化价格反应、入库并提醒，为建仓/加仓判断提供持续更新的素材。

## 1.2 系统定位与边界

| 项 | 说明 |
|---|---|
| 使用者 | 仅本人（单用户、本地运行、无需权限系统） |
| 分析对象 | 仅美股（USD 计价，不做汇率换算） |
| 输出 | 建仓/加仓/观望/减仓信号 + 理由 + 风险 + 免责声明 |
| 性质 | **辅助参考**，不自动下单、不接入券商、不构成投资建议 |
| 非目标 | 不做实时交易、不做多资产（A 股/加密）、不做自动交易策略 |

## 1.3 已确认决策（不可更改项）

| 项 | 决策 |
|---|---|
| 技术栈 | Python 3.13.9 + uv 管理（复用现有 pythonWorkspace 工程模式） |
| 股票池 | 空模板自填（配置文件，系统不预置任何股票） |
| 数据源 | 免费为主：yfinance（行情/财报）+ FRED（宏观）+ 新闻 RSS/Google News 主题流（事件）+ X 双通道（twitterapi.io API 推荐 / Playwright 爬虫，X_MODE 切换） |
| 交付形态 | 本地 Web 面板（FastAPI + Vue3 无构建链 + ECharts） |
| 事件跟进 | **准实时**：宏观政策/国际热点/行业/企业四类事件默认 20 分钟轮询增量采集（`EVENT_POLL_INTERVAL_MIN` 可配），新事件入库（含价格反应富化）+提醒 |
| 存储 | **MySQL 8**（用户指定；复用本机实例或 Docker 拉起） |
| LLM | 任意 OpenAI 兼容大模型（供应商/端点/模型名均 .env 配置，v1.2 起供应商无关，不绑定任何厂商） |
| 历史事件影响 | 内置种子事件库 + 用户可增补，检索 + LLM 精排两级类比 |
