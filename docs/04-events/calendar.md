# 04-事件库 ｜ 经济日历（预告 + 交易约束）

> 模块：04 历史事件库 ｜ 成分：日程预置 ｜ 对应代码：事件中心 + market.get_earnings_dates ｜ 实施阶段：P9
> 来源：原方案 §6.5（含 v1.1 交易约束）

事件中心内置可预见的日程，避免重要节点漏跟，与事件管道形成"**预告 → 实时跟进 → 历史类比**"闭环：

| 类型 | 内容 | 数据来源 |
|---|---|---|
| 美联储 | FOMC 会议日期（每年 8 次，官方年初公布全年日程）、决议日提醒 | 静态配置（每年更新一次） |
| 宏观数据发布 | CPI/PPI/非农/GDP 发布日期（惯例美东 8:30 发布） | 静态配置 + FRED 发布日历 |
| 财报日历 | 股票池公司的财报日期 | yfinance `get_earnings_dates`（[03-collectors/market.md](../03-collectors/market.md)） |

日历在"未来 7 天"视图展示，命中日程的日子自动在事件中心置顶预告。

## 交易约束（v1.1）

财报日历兼任**交易约束**（见 [breach-classification.md](breach-classification.md)）：财报/FOMC/重要数据发布前 N 天（默认 5）内，个股技术买点信号自动降级为"等事件落地"——避免在二元事件前夜给出买入倾向（实证：COHR 2026-07 技术破位买点 + 8/12 财报在前，"等落地"避开了其后连续两个月的下行）。
