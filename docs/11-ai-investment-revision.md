# AI 产业链研究方案修订（v1.4）

日期：2026-09-24。本修订覆盖旧文档中冲突的评分、降级、日历和回放约定。

## 定位与决策顺序

面向 AI 产业链成长投资，以经营兑现和估值纪律支持研究。四维总分仅是研究排序，不等于内在价值或买入概率。
决策顺序：财务证据与质量 → 价格隐含预期与情景估值 → 组合容量 → 催化剂与执行节奏。
数据不足时明确观望，不能因剔除缺失指标而提高行动强度。

| 研究环节 | 示例 | 核心证据 | 估值方法 |
|---|---|---|---|
| gpu | NVDA / AMD | 收入、利润率、现金流、产品竞争 | 增长与利润率情景 |
| custom_interconnect | MRVL | 客户项目量产、集中度、现金转化 | 项目兑现与正常化盈利 |
| optical | LITE / COHR | 光通信需求、产品结构、良率 | 周期正常化与分部估值 |
| turnaround | INTC | 制造执行、资本开支、现金消耗 | 分部与融资情景 |
| cloud | GOOG / GOOGL | 云与平台现金流、资本开支回报 | 分部现金流 |
| energy_infra | BE | 交付、单位经济性、融资与稀释 | 现金流与融资情景 |

分类显式由 stocks.yaml 选择，不修改用户股票池，不把示例自动加入持仓。产业动量只是市场与营收代理，不能标称为真实订单景气。

## 本次实现契约

1. 公司评分：缺失 FCF 不等于负值，ROE=0 不等于缺失；质量内部仅对已知项归一化。输出覆盖率和关键证据是否齐备（营收、毛利率、FCF）；缺失关键证据禁止增加风险。PE/营收增速明确为粗筛，不能生成目标价。
2. 真实采集补充 FCF、经营现金流、资本开支、净债务、股数及财报期/采集时间，保留来源；FCF 优先由同口径年度现金流计算。不得把未接入的多年财报、SEC 证据和情景估值描述为已完成。
3. 产业评分：一次分析预取完整相关篮子行情与财务，SPY 至少覆盖 63 个交易日；增加上述产业分类；财报中位数使用真正中位数。新闻词频与未标注 X 不作为经营证据。
4. 事件评分：同一当前事件的历史参考按相似度归一化，低于 0.6 不参与；同一历史 ID 在组内去重。不同当前事件可叠加，相关报道的机制级去重仍需后续建设。LLM 收到标的相关的真实案例指标，缺失不补造。
5. 风险约束：LLM 和规则输出均经过同一代码校验；未知体制/关键数据缺失/财报或 FOMC 三个自然日窗口 → 最高 watch；公司短板/已知破位 → 最高 watch_add。只允许输入池股票，每股恰好一条，缺失或重复输出回退规则。position_cap 为计划新增仓位的比例上限（1/0.3/0），不是总资产配置建议。
6. 时间：分析时间统一 America/New_York，另存行情所属交易日；同日分析不复用未经版本校验的旧缓存。FOMC 与财报日历共享服务；未知日历须标注，静态日历过期不得伪装完整。
7. 宏观：CPI 用同月去年观测计算 12 个月变化，不能以单月年化替代；分母缺失时中性并标注。
8. 审计：analysis_runs 追加保存完整评分输入、行情/财务/事件、权重、生成时间、提示词、模型与规则版本；每日 snapshot 仅作最新展示。保留原始 LLM 输出和约束后的最终结果。
9. 评测：按价格日期对齐行情，收益分母采用同一复权序列；同期基准仅包含当日有记录的股票；MAE 需完整窗口。置信度按动作分组：加仓为正超额、减仓为负超额，watch 不定义方向胜率。评测是信号研究，尚非可成交组合回测。

## 后续研究模块（不伪装为本次完成）

- SEC/公司 IR 多年财报与分部经营证据，记录发布时间、修订版本和原文出处。
- 保守/基准/乐观现金流与反向估值，显式录入增长、利润率、再投资、稀释、折现率及终值假设；无假设不输出价值区间。
- 投资论点、反证与失效条件；AI 资本开支共同风险与客户重叠。
- 实际持仓数量、现金与权重；长期组合评测、样本外验证、重叠样本处理和交易成本。

## 验收

离线回归必须覆盖：FCF 缺失/负值区别；只有成长时不得加仓；完整篮子传递；重复类比不放大；违规 LLM 输出被拦截；未知体制与事件窗口；美东日期与行情日期分离；CPI 跨年同月口径；按动作校准与同期股票池；审计输入可序列化。真实外部源与数据库联调单独报告。

## 历史初始化与覆盖审计

新增 `scripts/initialize_history.py`：默认离线审计，`--include-db` 合并库内 seed/user，auto 草稿单列；`--initialize` 按标的一次获取历史复权日线并按日缓存，断点重跑；`--refresh` 重取。输出在 data/history，不覆盖人工种子。

历史记录分两层：

1. 行情：事件前252日回撤/MA200乖离/20日涨幅/RSI，事件后1/5/20/60交易日收益、回撤与恢复，明确未上市/窗口不足/窗口未成熟。事件观察窗口不代表该公司受到事件因果冲击，不能自动作为新的事件标签入库。
2. 经营与估值：必须用当时已公开的财报、股数、现金债务及修订版本重建。现有工具不具备该数据源，输出 `requires_point_in_time_filings`，禁止用当前 Yahoo 财务值冒充历史。

2026-09-24 种子审计为43条，5条未兑现对照；NVDA有16条关联，LITE/MRVL/COHR/BE各1条，INTC3条，AMD与Google无直接关联。事件前四指标完整记录均为0。此规模可检索案例，不足以声称覆盖目标股票池，更不支持精确跌幅概率。DB不可用时仅报告种子范围，不宣称已审计用户积累库。

优先扩充各标的财报与指引、客户订单变化、产品交付、产能与良率、融资稀释、竞争格局等机制，并加入正面、未兑现和未恢复样本。机制核实后再标记影响对象；不能把八只股票机械附加到所有事件。

初始化行情后，真实分析通过 `enrich_from_initialized_history` 对既有关联补缺（按代码、事件ID、事件日期核对），不覆盖人工值，不新增因果标签；仅完整后观察窗口可补入回撤/恢复。输出带来源，未成熟窗口仍在观察文件中单列。
FOMC 2026 决策日依据 [美联储官方日历](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) 核对；其他年份明确未覆盖。
